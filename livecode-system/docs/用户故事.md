## 用户故事质量标准

本项目的所有用户故事遵循 **INVEST** 原则：

| 字母 | 原则 | 含义 | 本项目的检查方式 |
|------|------|------|-----------------|
| **I** | Independent（独立） | 故事可独立开发、测试和交付，尽量减少故事间依赖 | 每个故事都有独立的验收标准，不依赖其他故事完成才能验证 |
| **N** | Negotiable（可协商） | 故事是需求讨论的起点，不是最终合同，实现细节可调整 | 故事中标注了"可协商项"，允许实现时调整 |
| **V** | Valuable（有价值） | 每个故事对用户有明确可感知的价值 | 每个故事都有"以便"从句说明价值 |
| **E** | Estimable（可估算） | 团队能估算故事的工作量，粒度足够细 | 故事按功能点拆分，P0 故事单个估算 < 1 天 |
| **S** | Small（小型） | 故事足够小，可在迭代内完成 | 长故事拆分为多个子故事（如"文章管理"拆为5个） |
| **T** | Testable（可测试） | 有明确的验收标准，可客观判断是否完成 | 每个故事含 3~5 条可验证的验收标准 |

### 故事模板

```
**作为** <角色>
**我希望** <功能/能力>
**以便** <业务价值>

**验收标准：**
- <可验证的条件 1>
- <可验证的条件 2>
- ...

**可协商项：** （实现细节可调整的部分）
**工作量估算：** （开发时填入）
```

## 一、文章管理

### 1.1 创建文章

**作为** 管理员  
**我希望** 能创建一篇新文章，填写标题、正文（富文本）和上传图片  
**以便** 为后续生成活码准备内容  

**验收标准：**
- 标题必填，最多 200 字
- 正文支持富文本（加粗、斜体、列表、引用、链接、表格）
- 可上传多张图片，图片上传后直接显示在编辑器中
- 创建后默认状态为「草稿」
- 创建成功后自动跳转到文章列表

### 1.2 编辑文章

**作为** 管理员  
**我希望** 能修改已创建的文章内容  
**以便** 随时更新内容，而二维码不变  

**验收标准：**
- 编辑页面预填当前内容
- 修改后保存，已发布的文章立即生效（扫码用户看到新内容）
- 编辑历史不保留（第一版不做版本管理）

### 1.3 发布与切换草稿

**作为** 管理员  
**我希望** 能控制文章的发布状态，在「草稿」和「已发布」之间切换  
**以便** 内容准备好之后再公开，或临时下架内容  

**验收标准：**
- 草稿状态的文章，扫码用户无法看到（跳转后显示"内容未发布"提示）
- 已发布的文章，扫码用户正常访问
- 从已发布切换回草稿后，扫码立即不可见

### 1.4 删除文章

**作为** 管理员  
**我希望** 能删除不需要的文章  
**以便** 清理旧内容  

**验收标准：**
- 删除为软删除，数据保留在数据库
- 删除后，关联的活码仍存在但跳转显示"文章已删除"
- 删除后可以在后台列表中看到（但标记为已删除），或完全隐藏（取决于设计）

### 1.5 查看文章列表

**作为** 管理员  
**我希望** 能以列表形式查看所有文章，按创建时间排序，并支持搜索  
**以便** 快速找到需要的文章  

**验收标准：**
- 列表显示：标题、状态（草稿/已发布）、创建时间、更新时间
- 支持按标题搜索
- 支持按状态筛选
- 点击文章行进入编辑或详情页

## 二、活码管理

### 2.1 为文章生成活码

**作为** 管理员  
**我希望** 在文章发布后，为它生成一个或多个活码  
**以便** 将活码生成二维码印到不同物料上  

**验收标准：**
- 在文章详情页或活码管理页，点击「生成活码」按钮
- 系统自动生成一个 8 位随机字符串作为活码ID
- 活码生成后立即可用
- 一篇文章可以生成多个活码

### 2.2 停用与启用活码

**作为** 管理员  
**我希望** 能停用某个活码，或重新启用它  
**以便** 在物料不再使用时不浪费扫码统计，或恢复使用  

**验收标准：**
- 停用的活码，扫码后显示"活码已停用"提示
- 重新启用后扫码恢复正常
- 停用不影响其他活码和文章

### 2.3 删除活码

**作为** 管理员  
**我希望** 能删除不需要的活码  
**以便** 清理不再使用的入口  

**验收标准：**
- 删除后扫码显示"活码不存在"
- 软删除，数据保留

### 2.4 查看活码列表

**作为** 管理员  
**我希望** 能以列表形式查看所有活码，显示关联文章、扫码量、状态  
**以便** 快速了解每个活码的情况  

**验收标准：**
- 列表显示：活码ID、关联文章标题、扫码总量、状态（启用/停用）、创建时间
- 支持按文章筛选
- 支持按状态筛选
- 点击行进入活码详情页

## 三、二维码生成

### 3.1 在活码详情页查看并下载二维码

**作为** 管理员  
**我希望** 在活码详情页能看到实时生成的二维码，并可选择尺寸、Logo、边框文字  
**以便** 下载适合不同物料的二维码图片  

**验收标准：**
- 页面实时显示二维码（配置变化后立即刷新）
- 提供三种尺寸选择：小（200x200）、中（400x400）、大（600x600）
- 可选择平台 Logo 嵌入二维码中间
- 可自定义边框文字（如"扫一扫查看产品"）
- 点击「下载」按钮保存为 PNG 图片

### 3.2 批量生成二维码

**作为** 管理员  
**我希望** 能一次选择多个文章或活码，统一配置尺寸/Logo/边框文字，批量生成二维码并打包下载  
**以便** 一次性为多个物料准备二维码  

**验收标准：**
- 在文章列表或活码列表中勾选多项
- 统一配置尺寸、Logo、边框文字
- 点击「批量生成」后生成 ZIP 文件
- ZIP 内图片按活码ID命名（如 `a3kF9q.png`）
- 点击下载 ZIP

### 3.3 扫码用户一键生成二维码

**作为** 扫码用户  
**我希望** 在文章展示页上点击「生成二维码」按钮，直接下载当前文章的二维码  
**以便** 分享给他人  

**验收标准：**
- 文章展示页底部显示「生成二维码」按钮
- 点击后直接下载 PNG（中号尺寸 + 平台默认Logo + 默认边框文字）
- 无需任何配置，一键出图
- 下载的二维码指向当前活码

## 四、扫码跳转

### 4.1 扫码查看文章

**作为** 扫码用户  
**我希望** 扫描二维码后，在浏览器中打开一篇排版清晰的文章页面  
**以便** 阅读内容  

**验收标准：**
- 扫码后直接打开文章展示页，无需额外操作
- 页面在手机上显示良好（移动端适配）
- 页面展示：标题、发布时间、正文（富文本渲染）、图片
- 页面底部有「生成二维码」按钮

### 4.2 活码停用提示

**作为** 扫码用户  
**我希望** 扫描已停用的活码时，能看到明确的提示"该活码已停用"  
**以便** 知道原因而不是看到空白或错误页面  

**验收标准：**
- 停用活码扫码后显示友好提示页
- 页面包含必要的联系信息或说明

### 4.3 文章未发布提示

**作为** 扫码用户  
**我希望** 扫描关联到草稿文章的活码时，能看到"内容暂未发布"的提示  
**以便** 不会误以为系统故障  

**验收标准：**
- 显示友好提示页，而非错误页

## 五、扫码统计

### 5.1 查看扫码总量

**作为** 管理员  
**我希望** 在活码详情页看到该活码的累计扫码次数  
**以便** 了解该物料的扫码情况  

**验收标准：**
- 活码详情页显示扫码总量
- 显示今日扫码数、昨日扫码数
- 显示环比变化百分比（可选）

### 5.2 查看扫码趋势

**作为** 管理员  
**我希望** 能查看扫码次数的按天趋势图，并选择时间范围  
**以便** 分析扫码量随时间的变化  

**验收标准：**
- 折线图展示每天扫码次数
- 支持时间范围选择：近7天、近30天、自定义范围
- 图表使用 Chart.js 渲染

### 5.3 导出扫码数据

**作为** 管理员  
**我希望** 能将扫码记录导出为 Excel 或 CSV 文件  
**以便** 在本地做进一步分析或存档  

**验收标准：**
- 导出按钮在统计页面
- 支持导出格式：Excel (.xlsx)、CSV
- 导出内容包含：日期、扫码次数（每天一条）
- 文件名包含活码ID和时间范围
