# 人员管理需求文档

## 一、功能需求

### 1.1 人员列表

| 功能 | 状态 | 说明 |
|------|------|------|
| 表格展示 | ✅ | 一行一个成员，显示头像、姓名、职位、部门、联系方式、状态 |
| 搜索 | ✅ | 支持按姓名、职位、部门、邮箱搜索 |
| 状态筛选 | ✅ | 全部/在职/离职 |
| 分页 | ✅ | 每页10条，支持翻页 |
| 排序 | ❌ | 按创建时间、姓名、职位排序 |

### 1.2 人员详情

| 功能 | 状态 | 说明 |
|------|------|------|
| 基本信息展示 | ✅ | 姓名、职位、部门、头像 |
| 联系方式 | ✅ | 邮箱、电话、微信 |
| 个人简介 | ✅ | 富文本内容展示 |
| 二维码展示 | ✅ | 显示名片二维码 |
| 二维码下载 | ✅ | 下载PNG格式二维码 |
| 名片预览 | ✅ | 跳转到公开名片页 |

### 1.3 人员编辑

| 功能 | 状态 | 说明 |
|------|------|------|
| 基本信息编辑 | ✅ | 姓名、职位、部门、头像URL |
| 联系方式编辑 | ✅ | 邮箱、电话、微信 |
| 个人简介编辑 | ✅ | Quill富文本编辑器 |
| 编辑密码设置 | ✅ | 可选，设置后编辑需验证密码 |
| 头像上传 | ❌ | 上传图片而非URL |

### 1.4 人员操作

| 功能 | 状态 | 说明 |
|------|------|------|
| 添加成员 | ✅ | 填写信息后创建 |
| 编辑成员 | ✅ | 修改已有信息 |
| 删除成员 | ✅ | 确认后删除 |
| 停用/启用 | ✅ | 切换成员状态 |
| 编辑密码验证 | ✅ | 输入密码后获得编辑权限 |

### 1.5 名片页（扫码跳转）

| 功能 | 状态 | 说明 |
|------|------|------|
| 名片展示 | ✅ | 头像、姓名、职位、部门 |
| 联系方式 | ✅ | 邮箱、电话、微信（点击可操作） |
| 个人简介 | ✅ | 富文本内容展示 |
| 下载通讯录 | ✅ | 生成vCard格式文件 |
| 分享名片 | ✅ | 复制链接或调用系统分享 |

## 三、数据模型

### 3.1 团队成员表 (team_members)

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| id | Integer | ✅ | 主键 |
| name | String(100) | ✅ | 姓名 |
| position | String(100) | ❌ | 职位 |
| department | String(100) | ❌ | 部门 |
| email | String(200) | ❌ | 邮箱 |
| phone | String(50) | ❌ | 电话 |
| wechat | String(100) | ❌ | 微信 |
| avatar_url | String(500) | ❌ | 头像URL |
| bio | Text | ❌ | 个人简介（富文本） |
| code | String(16) | ✅ | 活码ID（唯一） |
| status | String(20) | ✅ | 状态：active/inactive |
| edit_password_hash | String(255) | ❌ | 编辑密码哈希 |
| extra_data | JSON | ❌ | 扩展字段 |
| created_at | DateTime | ✅ | 创建时间 |
| updated_at | DateTime | ✅ | 更新时间 |

## 四、API 接口

### 4.1 人员 API

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/v1/team` | 人员列表（支持搜索、状态筛选、分页） |
| POST | `/api/v1/team` | 添加成员 |
| GET | `/api/v1/team/{id}` | 成员详情 |
| GET | `/api/v1/team/by-code/{code}` | 通过活码ID获取成员（公开） |
| PUT | `/api/v1/team/{id}` | 更新成员 |
| DELETE | `/api/v1/team/{id}` | 删除成员 |
| POST | `/api/v1/team/{id}/verify-edit` | 验证编辑密码 |
| POST | `/api/v1/team/{id}/toggle-status` | 切换成员状态 |

### 4.2 页面路由

| 路由 | 页面 | 说明 |
|------|------|------|
| `/manage/team` | 人员列表 | 管理所有成员 |
| `/manage/team/create` | 添加成员 | 填写信息 |
| `/manage/team/{id}` | 成员详情 | 查看成员信息 |
| `/manage/team/edit/{id}` | 编辑成员 | 修改信息 |
| `/manage/member/{code}` | 名片页 | 扫码跳转（公开） |
