# 活码管理系统 - 腾讯云部署指南

## 一、购买服务器

1. 访问 https://buy.cloud.tencent.com/lighthouse
2. 选择配置：
   | 配置 | 推荐值 |
   |------|--------|
   | 地域 | 离你最近的（上海/广州/北京） |
   | 镜像 | **Ubuntu 22.04 LTS** |
   | 规格 | 2核2G（足够） |

## 二、安装 MySQL

```bash
# 安装 MySQL 8.0
apt update
apt install -y mysql-server
mysql_secure_installation

# 登录并创建数据库
mysql -u root -p
```

```sql
-- 创建数据库（utf8mb4 支持中文和 emoji）
CREATE DATABASE livecode_db CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;

-- 创建应用用户
CREATE USER 'livecode'@'localhost' IDENTIFIED BY '你的强密码';
GRANT ALL PRIVILEGES ON livecode_db.* TO 'livecode'@'localhost';
FLUSH PRIVILEGES;
```

## 三、部署代码

```bash
# 1. 安装依赖和工具
apt install -y python3 python3-pip python3-venv nginx git

# 2. 克隆代码
cd /var/www
git clone https://github.com/1452388/Project1.git livecode-system
cd livecode-system/livecode-system

# 3. 创建虚拟环境
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple

# 4. 配置环境变量
cp .env.example .env
```

编辑 `.env`：
```bash
DATABASE_URL=mysql+asyncmy://livecode:你的密码@localhost:3306/livecode_db
SECRET_KEY=随机生成的字符串
BASE_URL=https://hxy820.uno
DEBUG=false
```

## 四、建表并启动

```bash
# 运行迁移建表
alembic upgrade head

# 测试启动
uvicorn app.main:app --host 0.0.0.0 --port 8000
# 看到 "Application startup complete" 说明成功，Ctrl+C 停止

# 使用 systemd 长期运行
cp systemd/livecode.service /etc/systemd/system/
systemctl daemon-reload
systemctl enable livecode
systemctl start livecode
systemctl status livecode
```

## 五、配置 Nginx 域名

```bash
# 放置 Nginx 配置
cp nginx.livecode.conf /etc/nginx/sites-available/livecode
ln -s /etc/nginx/sites-available/livecode /etc/nginx/sites-enabled/
nginx -t && systemctl reload nginx
```

## 六、配置 HTTPS（腾讯云免费 SSL）

1. 控制台 → SSL 证书 → 申请免费证书（DV 型）
2. 域名 `hxy820.uno`、`www.hxy820.uno`
3. 下载 Nginx 格式证书
4. 上传到服务器 `/etc/ssl/livecode/`
5. 取消注释 `nginx.livecode.conf` 中 443 部分
6. `nginx -t && systemctl reload nginx`
